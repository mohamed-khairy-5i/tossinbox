Install

# Homebrew
brew install mohamed-khairy-5i/tap/tossinbox

# npm (from GitHub)
npm install -g github:mohamed-khairy-5i/tossinbox

# or run without installing
npx github:mohamed-khairy-5i/tossinbox spawn

How it works

1

Spawn

Create a brand-new disposable address in one command: tossinbox spawn

2

Wait

Block until the verification email lands: tossinbox wait --code

3

Toss

Delete it server-side and wipe local state: tossinbox toss

Built for AI agents

TossInbox ships an MCP server, so Claude, Cursor, and any MCP client can create inboxes and collect verification codes as native tools. Agent-first CLI: --json everywhere, documented exit codes, zero interactive prompts.
