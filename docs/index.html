Why TossInbox

TossInbox is a disposable email CLI and MCP server: one command spawns a throwaway inbox on a real mail provider, a second waits for the verification code and prints it, a third deletes the inbox. Humans read the output, agents parse the --json. No sign-up, no ads, no browser — and no ad-covered websites.

Machine-readable --json on every command. Agents parse stdout and move on; humans read the plain text.
Honest exit codes 0-4, documented: success, error, timeout, not found, usage. Scripts branch on the code, never on prose.
MCP server built in tossinbox mcp speaks Model Context Protocol — spawn, wait, read, and toss as agent tools.

Disposable by design. tossinbox toss deletes the inbox on the provider and wipes the local record — gone from the server, gone from disk. It receives, never sends, which is exactly why the providers tolerate it.
