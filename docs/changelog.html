0.1.0 2026-09-10

Added

  • First public release.
  • CLI: spawn, list, read, wait, inboxes, toss, clear,
  • MCP server over stdio with four tools: create_inbox, list_messages,
  • Providers: mail.tm (default) and GuerrillaMail — no API keys.
