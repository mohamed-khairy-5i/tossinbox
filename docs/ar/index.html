إيه هو TossInbox؟

TossInbox أداة بريد مؤقت عبر سطر الأوامر وخادم MCP. أمر واحد بيعمل إنبوكس مؤقت على مزود بريد حقيقي، وأمر تاني يستنى إيميل التفعيل ويطبع الكود، وأمر تالت يمسح الإنبوكس نهائيًا. البني يقرأوا النص، والوكلاء يقرأوا --json. بدون تسجيل، بدون إعلانات، وبدون متصفح.

التثبيت

محتاج Node.js 18+ بس. لا حسابات ولا API keys ولا ملفات إعدادات — أربع طرق واختار اللي ريحك.

Homebrew macOS وLinux brew install mohamed-khairy-5i/tap/tossinbox
npm حزمة جاهزة npm install -g tossinbox
npx بدون تثبيت npx tossinbox@latest spawn
من المصدر v0.1.3 git clone https://github.com/mohamed-khairy-5i/tossinbox.git && cd tossinbox && npm install && npm run build

ليه TossInbox؟

البريد المؤقت موجود كمواقع مليانة إعلانات وكسكريبتات للبشر على APIs ميتة. TossInbox هو الوحيد المبني للبرامج أصلًا.

  • tossinbox spawn بيعطيك إنبوكس حقيقي على مزود شغال. بدون تسجيل وبدون متصفح وبدون إعلانات.
  • tossinbox wait --code بيستنى لحد ما إيميل التفعيل يوصل، يطبع الكود، ويقفل نضيف. حطه في أي سكريبت.
  • tossinbox toss يمسح الإنبوكس: من السيرفر ومن الديسك. خلاص.
