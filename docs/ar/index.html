TossInbox · بريد مؤقت لوكلاء الذكاء الاصطناعي

TossInbox: بريد إلكتروني مؤقت عبر سطر الأوامر وخادم MCP لوكلاء الذكاء الاصطناعي. اعمل إنبوكس.
استنى الكود.
ارميه._

مبني للوكلاء أولًا: --json في كل أمر، أكواد خروج موثقة 0-4، وبدون أي أسئلة تفاعلية.

$ brew install mohamed-khairy-5i/tap/tossinbox
اعمل أول إنبوكس الآن
v0.1.1 MIT Node 18+ macOS · Linux · Windows
agent@laptop: zsh
$ tossinbox spawn
✔ Inbox ready : qwd6996p1lbc@uberip.com
  provider    : mailtm

$ tossinbox wait --code --from noreply@example.com
✔ code received
  from : ExampleApp <noreply@example.com>
  code : 9378412

$ tossinbox toss
✔ tossed qwd6996p1lbc@uberip.com
# gone from the server. gone from disk.

التثبيت

محتاج Node.js 18+ بس. لا حسابات ولا API keys ولا ملفات إعدادات — أربع طرق واختار اللي ريحك.

Homebrew macOS وLinux brew install mohamed-khairy-5i/tap/tossinbox
npm حزمة جاهزة npm install -g tossinbox
npx بدون تثبيت npx tossinbox@latest spawn
من المصدر v0.1.1 git clone https://github.com/mohamed-khairy-5i/tossinbox.git && cd tossinbox && npm install && npm run build

ليه TossInbox؟

TossInbox أداة بريد مؤقت عبر سطر الأوامر وخادم MCP: أمر واحد بيعمل إنبوكس مؤقت على مزود بريد حقيقي، وأمر تاني يستنى إيميل التفعيل ويطبع الكود، وأمر تالت يمسح الإنبوكس نهائيًا. البني يقرأوا النص، والوكلاء يقرأوا --json. بدون تسجيل، بدون إعلانات، وبدون متصفح.

مخرجات آلية --json في كل أمر. الوكيل يقرأ المخرجات ويكمل؛ البني يقرأوا النص العادي.
أكواد خروج صادقة 0-4 موثقة: نجاح، خطأ، مهلة، مش موجود، خطأ استخدام. السكريبت يفرّع على الكود مش على الكلام.
خادم MCP مدمج tossinbox mcp بيتكلم Model Context Protocol — spawn وwait وread وtoss كأدوات جاهزة للوكيل.

مصمم ليكون مؤقتًا. tossinbox toss بيمسح الإنبوكس من السيرفر ومن السجل المحلي — راح من السيرفر، راح من الديسك. بيستقبل وبيعتش أبدًا، وعلشان كده المزودين بيسامحوه.
